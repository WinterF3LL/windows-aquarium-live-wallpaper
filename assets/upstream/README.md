# Upstream aquarium assets

Selected assets were copied from [parisxmas/aquarium](https://github.com/parisxmas/aquarium), default branch `main`, on 2026-09-18.

- `fish/`: 3D Fish Pack by polyy.ai, CC0 1.0. The original `LICENSE.txt` is included.
- `backdrop/reef.jpg`: NOAA Photo Library reef scene, public domain. The original `SOURCE.txt` is included.
- `plants/vallisneria.jpg`: derived from a Vallisneria americana photograph by Auckland Museum, CC BY 4.0. The original `SOURCE.txt` is included.
- `materials/`: Google WebGL Aquarium rock and coral textures, BSD 3-Clause. The original `LICENSE.md` is included.

The source project supplied the reference implementation for model orientation and swim deformation. The Godot integration and cursor behavior live in this project's scripts and shaders.
